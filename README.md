# Algoritmos em C

Repositório criado para armazenar exercícios, desafios e projetos desenvolvidos durante meus estudos de lógica de programação e Linguagem C, as pastas estão numeradas por aula e tema principal abordado em sala.

## Conteúdos abordados
- Variáveis
- Entrada e saída de dados
- Estruturas condicionais
- Laços de repetição
- Vetores
- Algoritmos matemáticos

## Objetivo
Desenvolver fundamentos de programação, raciocínio lógico e boas práticas de desenvolvimento.
